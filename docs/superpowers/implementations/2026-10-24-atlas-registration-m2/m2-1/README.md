状态：`READY_FOR_ROOT_REVIEW`。功能三卡已有真实本地流程与耐久读回；开发日志缺口已修复、构建并切换，受影响的创建/替换两笔真实请求复验通过。Root 独立验收、Git 交付和真人验收均待，M2.2 未放行。

入口：**本体管理 → 数据源接入**，或从项目准备的“接入数据源”进入。先选当前获准项目；只有该项目当前管理员能管理连接。

## 本节点实现

- 创建新服务模式保存 Atlas 草稿；不创建 OM 服务、不尝试源连接。
- 已有服务模式只列当前项目批准的本地服务目录，保留原 UUID；尚未实时核验，也不读取或覆盖原服务秘密。
- 源密码只显示“已配置”和版本。编辑普通字段省略密码即 KEEP；详情里的显式替换产生新秘密版本，取消或提交结束清空输入。
- “设为本项目元数据接入连接”保存独立项目配置引用。创建连接本身不会自动引用，也不等于来源绑定、取数或发布就绪。
- 禁用先展示真实引用影响，再按原版本明确确认。配置、秘密版本、审计和历史保留；禁用后新使用被阻止。

连接测试、原生服务创建、元数据登记、来源绑定和业务查询不在 M2.1，M2.2 尚未放行。主机、节点、数据库和 TLS 取自平台批准策略；当前节点只有 `CONFIGURED_NOT_VERIFIED`，TLS REQUIRED 也只是配置。

## 维护边界

后台开关为 `atlas.ontology.metadata-connections.enabled`，默认关闭；开启还须提供服务器 `policy-file`、独立 `key-file` 和 `key-id`。密钥使用 JSON V1 信封、随机32字节主密钥，私有目录0700、文件0600；值和摘要不进入本交付。策略是平台一次配置，不允许浏览器输入任意 JDBC URL，不能为单项目手工补 Provider。

秘密使用独立 namespace 的 AES-GCM，绑定完整租户/空间/项目、连接 ID 和秘密版本；原秘密与新版本保留。丢失主密钥会导致已有秘密不可读；本节点没有自动主密钥迁移或轮换功能。备份密钥须沿现有私有运维机制完成，不能放进 Git、证据、URL 或日志。

DM36 的11条 CREATE已真实返回，7次只读核定完成。首轮 CHECK 表示差异停止原件保留，只追加剩余两次读，没有重放DDL。应用回退不删除六张表、密钥或历史。开发日志旧包 `19c4a12a…` 已发现合成密码漏记；回退应使用保留本次日志修复的包关闭功能开关，不应重新启用旧漏点来接收该命名空间。回退还须保留当前项目配置引用、秘密版本和所有原M1 UNKNOWN/停写闩；本次未执行实际回滚。

构建执行树与大 JAR 仅在本机 `/private/tmp`；证据中的 `source` 是执行 symlink，归档时只保存链接及哈希元数据，不跟随复制完整构建树、JAR 或任何私有配置。未执行实际回滚。
