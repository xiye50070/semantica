# M2.1 真人手动验收

状态：`PENDING`。以下清单不代表用户已验收；日志修后受影响两笔真实复验已通过，Root 技术验收和 Git 交付仍待。

1. 打开本体管理的“数据源接入”，选择自己的项目；普通成员不能管理。
2. 新建接入，只能选择批准的网络目标、执行节点、数据库范围、TLS 和 OM 实例。新服务模式保存后应显示“尚未检查/尚未创建”，刷新仍存在。
3. 切换已有服务模式，只能从本项目批准目录选择原 UUID；不能借其他项目的目录。没有可选服务时不得填造 UUID。
4. 普通编辑不出现旧密码，保存后秘密版本保持。显式替换确认默认取消；取消清空输入；明确替换后只显示新版本，不回显秘密。
5. 创建连接后，项目配置仍未选择。明确“设为本项目元数据接入连接”后，才出现项目配置引用与版本。
6. 禁用前能看到当前和历史配置引用、覆盖范围与有效期；信息不完整时不能确认。取消不改变版本；明确确认后刷新仍禁用、不能新使用，历史和原 OM 对象保留。
7. 不应出现连接测试成功、原生登记完成或业务可查询等越级状态。本节点中的执行节点/TLS仍只配置未验证。

页面已验代表与原件见 [README](README.md)。现有非工作样本不能用来测试源连接；后续真实诊断需在 M2.2 独立范围中执行。

当前未新增真实普通用户403/跨scope/伪secretRef HTTP验证；相应后台/前端有限证据与两次真实匿名401分开记录。当前浏览器代表为1512×806桌面，未冒窄屏、原生200%、跨浏览器或完整键盘生命周期通过。
