# M1.1 独立操作卡

依据唯一计划 §5 M1.1。验收仅涉及 Atlas 本地项目与准备框架；身份开户、原生权限、Glossary、Reviewer、元数据登记、业务行和正式发布查询不在本节点实现范围。

| 操作 | 独立判据 | 适用证据 |
| --- | --- | --- |
| 从获准知识空间新建项目；刷新或重新打开 | 项目从持久库读回；同一次请求重复提交返回原项目，换内容沿同 key 拒绝；不得重复创建 | 隔离数据库/API；浏览器入口与刷新 |
| 查看项目就绪页 | 项目本地存在；身份、原生写资格、目标/Reviewer、元数据/来源/授权、执行包/取数、正式发布/查询逐项显示实际未配置或未验证原因 | API 准确 12 项投影；页面可读呈现 |
| 保存本地准备草稿，重新打开 | 原草稿和版本可查；不存秘密；尚未实现的配置说明所需操作，不伪造完成、不跳到外部 OM | 隔离数据库/API；页面保存与恢复 |
| 创建初始化准备意图，重复同请求和冲突内容 | 同 scope/actor/operation key 返回同意图；不因 ACK 未知换 key；冲突内容明确拒绝 | 隔离数据库/API；合成界面反馈 |
| 首次 claim 与人工取消并发 | 同一持久行串行决定，只有一个胜出；claim 后即使 RETRY_WAIT 仍拒绝人工取消 | 有界并发测试及独立原件 |
| 重建服务实例查询原任务；回送陈旧 receipt | 原意图与历史存在；旧 attempt/lease/version receipt 不覆盖新结果 | 持久数据库隔离回归 |
| 任务 UNKNOWN | 仅保留原任务只读核对入口，没有“全部重试”、新建第二任务或撤销已发效果 | 状态测试；浏览器按钮与请求检查 |
| 未获准空间/项目或篡改准备记录 | 当前服务端身份解析 scope，拒绝跨租户/空间/项目；客户端 actor、role、秘密字段不建立授权 | API 反向测试 |
| 切项目或会话后晚到旧响应 | 新项目的草稿、就绪项与任务不被旧响应写入 | 延迟响应组件测试/浏览器隔离样例 |

浏览器必要样例使用合成身份与数据、ServiceWorker block、五代理关闭端口，以及未知 API/外部 HTTP/WS 阻断。合成写只验证前端，不证明真实 OM 或共享业务写。普通组件测试不冒像素、真实键盘或持久化证明。

前端核对正常桌面与必要窄屏的文字、错误、长说明、保存出口和键盘可达性；普通控件 32px、窄屏/触控 44px、长内容自然增长。失败保留草稿，异步后台状态允许离开，只有当前表单请求 pending 时短暂阻止离开。

每组结论必须指向实际版本、原始命令/退出码和失败记录。技术验收由 Root 记录，真人最终验收始终独立。
