# Atlas 项目初始化 M1 实施材料

本目录保存代码合同、准确前态、检查结果和独立验收材料。唯一进度账为[里程碑计划 §17](../../plans/2026-10-22-atlas-metadata-registration-milestones.md#17-m1实施与独立验收记录)，本目录不另记第二份状态账。

按原顺序实施 M1.1 → M1.2 → M1.3 → M1.4 → M1.5，每个节点独立验收后才放行下一个。M0 的[有限技术验收](../2026-10-22-atlas-registration-m0/evidence/root-m0-closeout-r1/acceptance.md)不是 Atlas 整链路或用户业务通过。

M1.1 的页面采用 Aham 8.0、pc 浅色、现有 React/AntD，复用现有项目入口与受控 Portal；新建项目不要求用户手填原生 UUID。只实现本地项目、就绪缺项、可恢复草稿和共用初始化意图框架。后续配置未实现时明确待配置，不发原生写或业务取数。

[M1.1 独立操作卡](m1-1-acceptance-card.md)列出本节点可复核行为。源码、隔离数据库/API、合成浏览器、真实环境与真人验收分别标注；不得互相替代。开发前的两仓在途改动按实际字节保护，不顺带清理或提交。
